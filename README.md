# 🚀 Geleceğin Teknolojileri - Web Blog Sayfası

Bu proje, **11. Sınıf Web Tabanlı Uygulama Geliştirme** dersi 3. Hafta uygulaması kapsamında geliştirilmiş, HTML5 standartlarına tam uyumlu ve SEO dostu bir blog makalesi sayfasıdır.

---

## 🛠️ Kullanılan Teknolojiler ve Yapı

- **HTML5 (Semantic Web):** Sayfa yapısı ve SEO uyumluluğu için `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>` ve `<footer>` etiketleri aktif olarak kullanılmıştır.
- **CSS3:** Sayfa düzeni için **Flexbox** mimarisi tercih edilmiş, şık gölgelendirmeler ve tipografi ayarları yapılmıştır.
- **Biçimlendirme & Medya:** Anlamsal etiketler (`<strong>`, `<em>`, `<time>`, `<figure>`, `<figcaption>`) kullanılarak içerik zenginleştirilmiştir.
